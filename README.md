# Esports Management System

## Introduction

Esports Management System is a simple Java-based project developed using Object-Oriented Programming concepts. The system is used to manage player records in an esports environment.

## Features

* Add a new player
* View all players
* Delete a player
* Store basic player information
* Manage player records
* Simple and easy-to-use menu

## Technologies Used

* Java
* Object-Oriented Programming
* Java Collections

## OOP Concepts Used

The project demonstrates important Java OOP concepts, including:

* Encapsulation
* Classes and Objects
* Inheritance
* Polymorphism
* Abstraction

## Main Operations

### Add Player

The user can add a new player by entering the required player information.

### View Players

The system displays the list of players currently stored in the system.

### Delete Player

The user can delete a player from the system by selecting the required player.

## How to Run

1. Install Java JDK on your computer.
2. Open the project in IntelliJ IDEA, Eclipse, NetBeans, or any Java-supported IDE.
3. Open the main Java file.
4. Compile the project.
5. Run the `Main.java` file.
6. Use the menu to add, view, or delete players.

## Purpose

The purpose of this project is to practice Java programming and understand how Object-Oriented Programming concepts can be used to create a simple management system.
